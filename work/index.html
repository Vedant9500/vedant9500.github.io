Not public

Some of what I’m building isn’t public yet. Not stealth-mode stuff, just repos that aren’t ready to be read by strangers. Here’s what I’m tinkering with:

assay
Automated code cleanup without LLMs. It only keeps a rewrite if the tests pass, golden outputs match, and it’s actually faster.
rt-approx
Approximated ray and path tracing on CPU and GPU. Seeing how much compute I can skip before the image actually degrades.
rusty-ocean
A real-time ocean renderer from scratch on WebGPU, with no engine or rendering library: Tessendorf FFT waves, whitecaps, sun glitter, and a physically based sky.
grist
Compact, append-only working memory format for coding agents. Uses 40.9% of the tokens JSON would, with lossless round-tripping. Reasoning held flat in its controlled test.
LiNN
A tiny (0.5M to 5M param) CPU-first chess net that outputs both policy and value, paired with a real move generator to keep moves legal.
CLOE
A Chrome MV3 extension for RAM, power, and load: capped preloading, script de-dupe, a declarative net guard, media lazy-loading, and DOM stripping.
VEA
A hardware-accelerated image viewer in Rust with a Photos-style gallery: month timeline, background scanning, thumbnail cache, search, and RAW, SVG, EXR, and AVIF support.
AD-DSP
System-wide Linux DSP that learns your EQ preferences per headphone using blind A/B tests.
Blastd
A real-time call-graph daemon for Rust, Python, and C++: who-calls queries in microseconds and token-budgeted context packets for agents.

If any of these overlap with what you’re working on (or you just want to see how one works), shoot me an email. Always happy to talk shop.
